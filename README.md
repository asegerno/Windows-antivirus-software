# Windows-antivirus-software

Windows 平台防毒軟體、安全套件與專殺工具資源索引庫 (Windows Antivirus & Security Software Resource Index).

---

## 📌 簡介 (Introduction)
本倉庫收錄與索引適用於 Windows 平台的防毒軟體、端點防護套件（EDR/EPP）、惡意程式專殺工具與離線急救工具資源，旨在提供合法、乾淨、安全之系統防護方案參考。

---

## 🛡️ 收錄防護類型 (Categories)

| 分類 | 說明 | 代表軟體 / 工具 |
| :--- | :--- | :--- |
| **企業級端點防護 (Enterprise)** | 適用於伺服器與企業工作站的高強度防護 | Kaspersky Endpoint Security (KES), Bitdefender GravityZone |
| **個人/家用安全套件 (Consumer)** | 適用於日常防護、即時防禦與網路防火牆 | Avira, Dr.Web, F-Secure, Windows Defender |
| **輔助查殺與專殺工具 (Remediation)** | 適用於系統中毒急救、頑固 Rootkit 清除 | Malwarebytes (MBAM), Dr.Web CureIt!, UnHackMe |
| **勒索病毒與漏洞防禦 (Anti-Exploit)** | 專門防護記憶體注入、零日漏洞與勒索加密 | A1RunGuard, XenArmor |
